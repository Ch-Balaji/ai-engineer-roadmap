## The Channel In One Paragraph

[Roadmap 2026](https://www.youtube.com/@balajichippada) is a free, 9-phase Agentic AI curriculum delivered by Balaji Chippada — an AI engineer based in Netherlands, working remote for the largest telecom in Switzerland. Audience: working IT pros stuck in legacy stacks, freshers (incl. non-IT branches), ML/DS upskillers, SWEs pivoting to AI, and final-year students. Delivery in Telugu, all written content in English, technical jargon never translated. Schedule: Mon/Wed/Fri 7 PM IST tutorials + Sunday 1-hour live doubt-clearing.

## Per-Video Workflow (the canonical sequence)

1. **Pick the topic** from `site/data.js` phase + section. Confirm prerequisites are already published. (skill 04)
2. **Lock the hook**. Generate 5, pick 1. (skill 07)
3. **Pick (or skip) the personal story** for opener / mid / closer. (skill 02)
4. **Draft the script** using `video-script-template.md`. Apply voice rules. (skill 01)
5. **Brief the thumbnail + title** as one locked artifact. (skill 06 + skill 03)
6. **Plan visuals**: which segments are screen-record, which are sketchbook (iPad GoodNotes sidecar), which are face-cam-led. (skill 03)
7. **Record** on Mac screen + Insta360 webcam PiP + DJI mic. Edit in CapCut.
8. **Build the GitHub repo** for this video (per video, clean, small).
9. **Publish** on the right MWF slot. Description includes roadmap mapping + repo link + form link (Phase-1 hint per skill 09).
10. **Plan the Short** repurposing for the next off-day. (skill 05)
11. **Reply to comments** in first 48 hours.
12. **Mine comments** through the week for Sunday live. (skill 08)

## Production Setup (locked)

| Component | Tool / Spec |
|---|---|
| Primary capture | Mac screen recording (`Cmd+Shift+5` or QuickTime / OBS) |
| Face camera | Insta360 4K webcam (PiP overlay in CapCut) |
| Audio | DJI Mic (lavalier) |
| Whiteboard | iPad as Sidecar display, GoodNotes app, cream paper template + rust + teal-deep ink (no yellow/pink markers — see skill 03) |
| Editing | CapCut — single project per video |
| Captions | CapCut auto-caption + manual yellow-highlight on keywords |
| Subtitles | English subtitles required on every video (since delivery is Telugu) |
| Thumbnail design | Photopea / Canva / ChatGPT image — per skill 03 + 06 |

## What This Channel WILL NOT Do

- Translate technical terms into Telugu (`vector database`, `agent`, `RAG` stay English)
- Open with "hey guys, welcome to my channel"
- Address the audience as "guys" — direct, single-person address only
- Clickbait — title and thumbnail must deliver
- Pitch paid products before Phase 2 (skill 09)
- Toy-only examples without production notes
- Hide errors / show only the happy path
- Skip the MWF schedule
