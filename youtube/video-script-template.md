## Pre-Record Checklist

- [ ] Hook is ≤30s and creates a knowledge gap (skill 07)
- [ ] Voice rules applied (no "guys", direct address, English jargon preserved — skill 01)
- [ ] Story (if used) is on its allowed cooldown (skill 02)
- [ ] Roadmap mapping filled (skill 04)
- [ ] Thumbnail + title brief locked (skill 06)
- [ ] Production plan per segment matches recording setup
- [ ] GitHub repo skeleton created
- [ ] Open loop planted in problem section, resolved later
- [ ] Common mistakes section includes one real error
- [ ] Cliffhanger to next video written
- [ ] Description block ready
- [ ] Phase 1 monetization rules respected (skill 09)

## Post-Record Checklist

- [ ] Length 15–25 min (6–10 for recap, 30+ for capstone)
- [ ] At least 3 medium switches
- [ ] Burned captions added in CapCut, yellow on keywords
- [ ] English subtitles file uploaded with the video
- [ ] PiP webcam framing checked, face visible
- [ ] Audio levels consistent
- [ ] Code on screen at readable font (16pt+)
- [ ] Thumbnail produced per skill 03 / skill 06
- [ ] End screen points to next video + playlist
- [ ] Story usage logged in `skills/02-story-bank/STORIES.md`
