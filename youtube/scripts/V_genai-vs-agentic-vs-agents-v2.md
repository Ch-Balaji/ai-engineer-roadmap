## The Core Idea

One task. Five levels. Each level reveals a new concept by hitting a wall.

```
THE TASK: "Help me get this job."

Level 1 — Generative AI    → ChatGPT writes your resume bullet. You do everything else.
Level 2 — Tool Use          → ChatGPT reads the JD from a URL and searches for jobs. But you still orchestrate.
Level 3 — AI Agent          → One agent does the full workflow: read JD → match skills → rewrite → cover letter.
Level 4 — Multi-Agent       → Specialist agents: JD Extractor, Resume Matcher, Rewriter, Critic, each doing one job.
Level 5 — The Vision        → Agents find 50 jobs, filter, tailor, apply — you wake up with interviews.
```

## SCENE 5 — LEVEL 3: AI AGENT (6:30 – 9:30)

**[Title card on screen: "LEVEL 3 — AI Agent: One Instruction, Full Workflow"]**

**On screen**: Sketchbook → Mac screen (terminal demo).

**Spoken**:

> This is where it gets real.
>
> An AI Agent is not just a model with tools. It's a model with tools AND a loop.
>
> **[Sketchbook: draw the agent architecture]**
>
> **[Draw a central circle: "LLM (the brain)"]**
> **[Draw connected boxes: "Tools" / "Memory" / "Orchestration Loop"]**
>
> The loop is what changes everything. Let me draw it.
>
> **[Draw the loop: THINK → ACT → OBSERVE → back to THINK]**
>
> Step 1 — **Think.** The agent reads Ravi's task and decides: "First, I should analyze the JD to extract keywords."
>
> Step 2 — **Act.** It calls a tool — the JD extractor. Sends the JD text. Gets back keywords: LLM, RAG pipelines, embeddings, vector search, prompt engineering. Seniority: mid-senior.
>
> Step 3 — **Observe.** It reads the result. "Okay, the top keywords are: RAG, vector database, prompt engineering, production ML."
>
> Then back to **Think.** "Now I should match Ravi's resume against these keywords." It calls the resume matcher. Gets a match score — 52%. Matched: Python, REST APIs, backend services. Missing: LLM, RAG, vector database, embeddings.
>
> **Think** again. "Score is 52%. Ravi has no direct AI keywords, but his backend and automation experience maps well. I should rewrite the weak bullets to bridge the gap." Calls the rewriter.
>
> **Think** again. "Bullets are done. Now write a cover letter." Calls the cover letter writer.
>
> **Think** one more time. "Is this good enough? Let me review." Calls a critic function. The critic says: "Score 6/10. The cover letter is too generic. Suggestion: emphasize the data extraction automation as a retrieval pipeline precursor."
>
> **Think.** "Score is below 8. Let me revise." It revises the cover letter, re-scores — 8/10. Pass.
>
> **[Point to the loop on the sketchbook]**
>
> I gave it one instruction. It planned 6 steps, executed them, evaluated its own work, revised, and delivered. I didn't tell it the order. I didn't tell it to revise. The loop decided.
>
> Let me show you this in code.
>
> **[Switch to Mac screen — terminal]**
>
> **[LIVE DEMO — Agent with think-act-observe loop]**

```python
from openai import OpenAI
import json

client = OpenAI()

tools = [
    {
        "type": "function",
        "function": {
            "name": "analyze_jd",
            "description": "Extract keywords, required skills, and seniority from a job description",
            "parameters": {
                "type": "object",
                "properties": {
                    "jd_text": {"type": "string", "description": "The job description text"}
                },
                "required": ["jd_text"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "match_resume",
            "description": "Compare resume against JD keywords and return a match score (0-100)",
            "parameters": {
                "type": "object",
                "properties": {
                    "resume_text": {"type": "string", "description": "Resume text"},
                    "keywords": {"type": "string", "description": "Comma-separated JD keywords"}
                },
                "required": ["resume_text", "keywords"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "rewrite_bullets",
            "description": "Rewrite resume bullets to better match JD keywords",
            "parameters": {
                "type": "object",
                "properties": {
                    "resume_text": {"type": "string", "description": "Original resume text"},
                    "keywords": {"type": "string", "description": "Target keywords to weave in"}
                },
                "required": ["resume_text", "keywords"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "write_cover_letter",
            "description": "Write a 3-paragraph cover letter mapping resume strengths to JD requirements",
            "parameters": {
                "type": "object",
                "properties": {
                    "resume_text": {"type": "string", "description": "Resume text"},
                    "job_title": {"type": "string", "description": "Target job title"},
                    "keywords": {"type": "string", "description": "JD keywords to emphasize"}
                },
                "required": ["resume_text", "job_title", "keywords"]
            }
        }
    }
]

# Simulated tool implementations
def analyze_jd(jd_text):
    return json.dumps({
        "keywords": ["RAG", "vector database", "FastAPI", "production ML", "LLM deployment"],
        "must_have": ["Python", "LLM experience", "API development"],
        "seniority": "Mid-Senior"
    })

def match_resume(resume_text, keywords):
    return json.dumps({
        "score": 52,
        "matched": ["Python", "REST APIs", "backend services", "automation"],
        "missing": ["LLM", "RAG", "vector database", "embeddings", "prompt engineering"],
        "verdict": "Low-moderate match. Strong backend foundation but no direct AI/LLM experience. Resume needs significant keyword alignment."
    })

def rewrite_bullets(resume_text, keywords):
    return json.dumps({
        "bullets": [
            "Built scalable backend services and REST APIs using Python and Flask, supporting AI-ready internal tooling",
            "Developed automated data retrieval pipelines reducing manual extraction effort by 40%, foundational to production ML workflows",
            "Supported production deployments with on-call incident resolution, ensuring reliability and observability of critical systems",
            "Contributed to reusable internal frameworks and automation workflows across cross-functional engineering teams"
        ]
    })

def write_cover_letter(resume_text, job_title, keywords):
    return "Dear Hiring Manager,\n\nWith 4 years building production backend systems at Infosys and TCS — from scalable REST APIs to automated data retrieval pipelines — I bring the engineering discipline that AI-powered products demand at scale...\n\n[3-paragraph cover letter tailored to the JD]"

TOOL_MAP = {
    "analyze_jd": analyze_jd,
    "match_resume": match_resume,
    "rewrite_bullets": rewrite_bullets,
    "write_cover_letter": write_cover_letter,
}

def run_agent(task: str):
    print(f"\n{'='*60}")
    print(f"TASK: {task}")
    print(f"{'='*60}")

    messages = [
        {"role": "system", "content": (
            "You are a job application assistant agent. Given a resume and job description, "
            "you must: 1) analyze the JD, 2) match the resume, 3) rewrite weak bullets, "
            "4) write a cover letter. Use the provided tools. Think step by step."
        )},
        {"role": "user", "content": task}
    ]

    step = 0
    while step < 10:
        step += 1
        response = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=messages,
            tools=tools,
            tool_choice="auto"
        )

        msg = response.choices[0].message

        if msg.tool_calls:
            messages.append(msg)
            for tc in msg.tool_calls:
                fn = tc.function.name
                args = json.loads(tc.function.arguments)
                print(f"\n🔧 STEP {step} — THINK → ACT: calling {fn}")
                result = TOOL_MAP[fn](**args)
                print(f"   OBSERVE: {result[:120]}...")
                messages.append({"role": "tool", "tool_call_id": tc.id, "content": result})
        else:
            print(f"\n{'='*60}")
            print("FINAL ANSWER:")
            print(msg.content)
            break

RESUME = """RAVI KUMAR REDDY — Software Engineer, Hyderabad
Infosys (2021-2023): Developed REST APIs using Python and Flask for internal tools.
